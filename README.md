# heygabo.dev

Personal portfolio site — [heygabo.dev](https://heygabo.dev)

## Stack

- React + Vite
- Tailwind CSS
- i18n (react-i18next) — English / Spanish
- Deployed on Vercel

## Features

- Snap-scroll single-page layout with a side nav that tracks scroll position
- Light / dark mode
- Fully bilingual content (EN/ES), including project descriptions and experience entries
- Downloadable resume (PDF)

## Running locally

```bash
npm install
npm run dev
```

## Deployment

Connected to Vercel via GitHub — pushes to `main` deploy automatically.
